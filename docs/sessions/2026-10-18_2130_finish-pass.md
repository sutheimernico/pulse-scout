## Changes

1. `OllamaClient` takes a wall-clock `deadline`; each call's timeout is capped to the remaining
   budget and no call starts after it. `build_digest.py` sets 2 h (normal run: 5-15 min).
2. A run that writes no digest (model error, dry run) deletes the items it recorded as new
   (`repo.forget_items_first_seen_at`), so the retry sees them.
3. `observe.py` prints "Kein Digest an: ..." for every gap.
4. README, `docs/ops.md` ("When a day is missing"), observation log note updated.

## Decisions

- No systemd unit changes (not allowed in this pass; the deadline makes them unnecessary).
- Wall clock for the budget on purpose: a host sleep mid-run aborts the run instead of resuming it.
  Chosen over a multi-day hang; the next start retries.
